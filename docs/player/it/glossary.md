# Glossario

|                                                                            | Parola                 | Significato                                                                                                                                                                                                                       |
| -------------------------------------------------------------------------- | ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|                                                                            | Adrenalina             | Ciò che alcune abilità costano al posto dell'Energia; si guadagna mettendo a segno i colpi                                                                                                                                        |
|                                                                            | Aftercast              | La breve pausa dopo un lancio; un'abilità premuta in quel momento parte subito dopo                                                                                                                                               |
|                                                                            | Build                  | Le professioni, le otto abilità, gli attributi e l'equipaggiamento di un personaggio                                                                                                                                              |
|                                                                            | Nemico segnalato       | Il nemico che la tua squadra deve attaccare; **T** lo bersaglia                                                                                                                                                                   |
|                                                                            | Condizione             | Un effetto dannoso come ![Sanguinamento](../../../apps/web/public/icons/status/bleeding.svg) **Sanguinamento** o ![Azzoppato](../../../apps/web/public/icons/status/crippled.svg) **Azzoppato**; svanisce da solo o viene rimosso |
|                                                                            | Acqua profonda         | Acqua in cui non puoi entrare; colpi e incantesimi la attraversano                                                                                                                                                                |
|                                                                            | Facile da interrompere | Qualsiasi colpo che va a segno mentre la usi la interrompe, come quando piazzi una trappola                                                                                                                                       |
|                                                                            | Élite                  | Un'abilità potente con la cornice dorata; una per barra                                                                                                                                                                           |
| ![Incantamento](../../../apps/web/public/icons/skill-type/enchantment.svg) | Incantamento           | Un effetto positivo lanciato da te o da un alleato                                                                                                                                                                                |
|                                                                            | Energia                | Ciò che costa la maggior parte delle abilità; torna da sola                                                                                                                                                                       |
| ![Maleficio](../../../apps/web/public/icons/skill-type/hex.svg)            | Maleficio              | Un effetto negativo lanciato su di te da un nemico                                                                                                                                                                                |
|                                                                            | Insegna                | Un potenziamento dell'armatura: un piccolo extra su un pezzo, spesso più armatura                                                                                                                                                 |
|                                                                            | Interruzione           | Fermare l'abilità di un nemico mentre la lancia, o il suo attacco a metà colpo                                                                                                                                                    |
|                                                                            | Atterramento           | Finire a terra: non puoi muoverti, attaccare o lanciare                                                                                                                                                                           |
|                                                                            | Mantenuto              | Un incantamento che dura finché non lo termini, e consuma Energia finché è attivo                                                                                                                                                 |
|                                                                            | Morale                 | -15% per ogni morte, fino a -60%; riduce Salute ed Energia                                                                                                                                                                        |
|                                                                            | Pip                    | Una freccia su una barra: Salute o Energia che tornano o calano                                                                                                                                                                   |
|                                                                            | Attributo primario     | L'attributo che ha solo la tua professione primaria, segnato con ★                                                                                                                                                                |
|                                                                            | Ricarica               | Il tempo che deve passare prima di poter riusare un'abilità                                                                                                                                                                       |
|                                                                            | Resuscitare            | Riportare in vita un alleato morto                                                                                                                                                                                                |
|                                                                            | Runa                   | Un potenziamento dell'armatura: gradi di attributo, Salute, Energia o condizioni più brevi                                                                                                                                        |
|                                                                            | Acqua bassa            | Acqua che guadi a tre quarti della tua velocità                                                                                                                                                                                   |
|                                                                            | Sigillo (scudo)        | Il tuo segno, un piccolo scudo ricavato dall'identità del tuo browser, davanti al tuo nome                                                                                                                                        |
|                                                                            | Spawn                  | Il punto in cui la tua squadra inizia la partita                                                                                                                                                                                  |
|                                                                            | Abilità a tocco        | Un'abilità che si usa toccando il bersaglio; alcuni gridi fanno fallire i tocchi dei nemici                                                                                                                                       |
|                                                                            | Set di armi            | Un'arma e una mano secondaria; ne porti fino a quattro                                                                                                                                                                            |
