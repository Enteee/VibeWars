# 操作

下の表のキーはすべて、**オプション**の**操作**で変更できます。Esc、Enter、F10とマウスボタンは固定です。そこで**プリセット**を選ぶか、キーのセルをクリックして使いたいキーを押します。すでに使われているキーは新しい操作に移り、どの操作からキーが外れたかが画面に表示されます。変更はすぐに保存されます。

## キー

標準のプリセットは**VibeWars**です。**クラシック**はGW1に慣れた手のためのものです。

| 操作                       | VibeWars         | クラシック              |
| -------------------------- | ---------------- | ----------------------- |
| スキル1～8                 | Q W E R, A S D F | 1～8                    |
| 移動                       | 矢印キー         | W A S D、または矢印キー |
| 武器セット1～4             | 1～4             | F1～F4                  |
| 攻撃、または旗を使う       | Space            | Space                   |
| 次の敵（Shift: 前の敵）    | Tab              | Tab                     |
| 最も近い敵                 | C                | C                       |
| チームのコールした敵       | T                | T                       |
| 自分                       | G                | G                       |
| 名前を表示（長押し）       | Shift            | Shift                   |
| ミュート                   | M                | M                       |
| 旗・レリック・遺灰を捨てる | なし             | なし                    |

次のキーは固定です。

- **Esc**は、している最中のこと（詠唱、攻撃、移動）をキャンセルします。もう一度押すと、ターゲットを解除します。ヘルプとオプションも閉じます。
- **Enter**でチャットを開きます。左下のチャットアイコンをクリックしても開けます。Enterで送信し、Escで閉じます。行を`!`で始めると全員に、`#`で始めると自分のチームだけに話します。閉じている間、チャットには最新の行だけが表示され、数秒で消えていきます。クリックはチャットを通り抜けます。
- **F10**は、マッチを退出するかどうかを尋ねます。

## マウス

- 地面を**左クリック**すると、そこへ歩きます。Shiftを押していなければ、左ボタンは歩くだけです。
- 高台のあるマップでは、左クリックは見えている面へ、**Alt + 左クリック**はその下の地面へ向かいます。カーソルの下のリングは高台を、破線のリングは地面を示します。
- 敵や味方を**右クリック**すると、ターゲットにします。同じ敵をもう一度素早く右クリックすると、攻撃します。
- ギルドバトルやBarrow Fieldで旗や旗台を**右クリック**すると、ターゲットにします。**Space**でそこへ歩き、旗を拾うか立てます。
- レバーを**右クリック**するとターゲットにします。**Space**でそこへ歩いてレバーを倒し、それが動かす門を開け閉めします。
- **ポータル**に入ると、その出口へ移されます。レバーでオン・オフが切り替わることがあり、一度移動すると次に運んでくれるまで5 s休みます。
- **きらめく門**は矢と体を止めますが、呪文は止めません。**ひび割れた壁**は壊せます。クリックしてから攻撃するか、ダメージスキルを当ててください。
- 敵を**ホイールクリック**すると、チームにコールします。味方の**T**がその敵をターゲットにします。地面や味方をホイールクリックすると、その場所にピンを打ちます。上部のターゲットバーをクリックしても、ターゲット中の敵をコールできます。
- コンパスをクリックすると、その場所をチームにピンで知らせます。コンパス上でドラッグすると、味方に数秒間見える線を描けます。
- **ホイール**でズームします。**右ドラッグ**で周りを見回し、離すと視点はあなたのところへ滑らかに戻ります。
- バーのスキルをクリックすると使い、パーティーウィンドウの名前をクリックするとその味方をターゲットにします。
- **名前を表示**（Shift）を押し続けると、すべての名前が表示され、各プレイヤーの名前の前にはシグネットが付きます。シグネットは小さな盾で、同じプレイヤーならいつも同じです。押している間は、キャラクターの名前をクリックすると、その体をクリックしたのと同じように動作します。右クリックは2回でもターゲットするだけ、左クリックはターゲットと攻撃を同時に行い、ホイールクリックはコールかピンを行います。クリックが当たる名前は強調表示されます。

## トップバー

マッチの外では、トップバーには **[?]**（このヘルプ）、**⚙**（オプション）、**ロビー**（招待リンク、ロビーに参加、公開/閉鎖中、退出、ロビーにいる人。バッジは人数を数えます）、**♪**（音楽: 何をどのくらいの音量で再生するか）、サウンドのミュートと全画面表示があります。マッチ中は同じボタンが、ロビーを除いて、画面の右上に並びます。狭いウィンドウでは、これらのアイコンと画面のほかのボタンは **⋯** にまとめられ、メインのボタンだけが外に残ります。⚙はバーの下にウィンドウとしてオプションを開き、画面はその後ろに残ります。Esc、×、または外側のクリックで閉じます。**表示**の**ライティング**は、照明のあるマップの光と影をすぐにオン/オフします。マッチ中でも可能です。ヘルプは右上の×、Esc、または [?] をもう一度押すと閉じます。

**ロビーとビートを共有する。** ビートエディター（♪、次に**編集**）で、**ロビーに共有**を押すと、入力した内容を保存済みかどうかにかかわらず、あなたがホストしたロビー、またはリンクで参加したロビーのほかの全員に送ります（キューで見つかったロビーには送れません。最大8 KB、10秒に1回まで）。相手には♪にバッジが表示され、そのウィンドウの**共有された曲**に、プレイヤーごとに「Ann · Ember Deep」のような行が**再生**とともに並びます。再生を押すまで何も鳴らず、マッチの外でしか再生できません。**自分の音楽に戻す**で自分の音楽に戻ります。共有されたビートは保存されず、ロビーを離れるか再読み込みすると消えます。

自動では、メニューは奥へ進むほど盛り上がる1つの曲を共有し、各マップにはいつも専用の曲があります。
