# Słownik

| Słowo                | Znaczenie                                                                                    |
| -------------------- | -------------------------------------------------------------------------------------------- |
| Adrenalina           | To, czym niektóre umiejętności płacą zamiast Energii; zdobywasz ją trafieniami               |
| Aftercast            | Krótka przerwa po rzuceniu; umiejętność wciśnięta w jej trakcie idzie następna               |
| Build                | Profesje postaci, osiem umiejętności, atrybuty i ekwipunek                                   |
| Wskazany wróg        | Wróg, którego drużyna ma atakować; **T** obiera go na cel                                    |
| Dolegliwość          | Szkodliwy efekt, np. Bleeding lub Crippled; mija z czasem lub zostaje usunięty               |
| Łatwo przerywana     | Każde trafienie w trakcie jej użycia ją przerywa, np. przy zakładaniu pułapki                |
| Elitarna             | Silna umiejętność w złotej ramce; jedna na pasek                                             |
| Zaczarowanie         | Korzystny efekt rzucony przez ciebie lub sojusznika                                          |
| Energia              | To, czym płaci większość umiejętności; odnawia się sama                                      |
| Klątwa               | Szkodliwy efekt rzucony na ciebie przez wroga                                                |
| Insygnia             | Ulepszenie pancerza: mały dodatek na jednej części, często więcej pancerza                   |
| Przerwanie           | Zatrzymanie umiejętności wroga podczas jej użycia albo jego ataku w połowie zamachu          |
| Powalenie            | Rzucenie na ziemię: bez ruchu, ataków i rzucania                                             |
| Podtrzymywane        | Zaczarowanie trwające do czasu, aż je zakończysz; kosztuje Energię, gdy działa               |
| Morale               | -15% za każdą śmierć, do -60%; zmniejsza Zdrowie i Energię                                   |
| Pip                  | Jedna strzałka na pasku: Zdrowie lub Energia wraca albo ubywa                                |
| Główny atrybut       | Atrybut dostępny tylko dla głównej profesji, oznaczony ★                                     |
| Odnowienie           | Czas, zanim użytej umiejętności można użyć ponownie                                          |
| Wskrzeszenie         | Przywrócenie poległego sojusznika                                                            |
| Runa                 | Ulepszenie pancerza: rangi atrybutu, Zdrowie, Energia lub krótsze dolegliwości               |
| Sygnet (tarcza)      | Twój znak, mała tarcza z tożsamości twojej przeglądarki, przed twoją nazwą                   |
| Spawn                | Miejsce, w którym twoja drużyna zaczyna mecz                                                 |
| Umiejętność dotykowa | Umiejętność użyta przez dotknięcie celu; niektóre okrzyki sprawiają, że dotyk wrogów zawodzi |
| Zestaw broni         | Broń i przedmiot do drugiej ręki; nosisz do czterech                                         |
