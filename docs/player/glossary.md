# Glossary

| Word               | Meaning                                                                   |
| ------------------ | ------------------------------------------------------------------------- |
| Adrenaline         | What some skills cost instead of Energy, won by landing hits              |
| Aftercast          | The short pause after a cast; a skill pressed in it goes next             |
| Build              | A character's professions, eight skills, attributes and equipment         |
| Called foe         | The foe your team was told to attack; **T** targets it                    |
| Condition          | A harmful effect such as Bleeding or Crippled; it wears off or is removed |
| Easily interrupted | Any hit that lands while you use it interrupts it, as setting a trap      |
| Elite              | A strong skill with a gold frame; one per bar                             |
| Enchantment        | A good effect cast by you or an ally                                      |
| Energy             | What most skills cost; it comes back by itself                            |
| Hex                | A bad effect cast on you by a foe                                         |
| Insignia           | An armor upgrade: a little extra on one piece, often more armor           |
| Interrupt          | Stopping a foe's skill while they cast it, or their attack mid-swing      |
| Knockdown          | Being thrown to the ground: no moving, attacking or casting               |
| Maintained         | An enchantment that lasts until you end it, costing Energy while it runs  |
| Morale             | -15% per death, down to -60%; it shrinks your Health and Energy           |
| Pip                | One arrow on a bar: Health or Energy coming back or draining              |
| Primary attribute  | The attribute only your primary profession gets, marked ★                 |
| Recharge           | The time before a used skill can be used again                            |
| Resurrect          | To bring a dead ally back                                                 |
| Rune               | An armor upgrade: attribute ranks, Health, Energy or shorter conditions   |
| Spawn              | Where your team starts the match                                          |
| Touch skill        | A skill used by touching the target; some shouts make foes' touches fail  |
| Weapon set         | A weapon and an off-hand; you carry up to four                            |
