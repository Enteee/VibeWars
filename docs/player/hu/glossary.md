# Szójegyzék

| Szó                    | Jelentés                                                                                       |
| ---------------------- | ---------------------------------------------------------------------------------------------- |
| Adrenalin              | Amibe egyes készségek Energia helyett kerülnek; találatokkal gyűlik                            |
| Utóvarázslás           | A rövid szünet egy varázslás után; az ekkor lenyomott készség jön következőnek                 |
| Build                  | Egy karakter kasztjai, nyolc készsége, tulajdonságai és felszerelése                           |
| Bemondott ellenség     | Az ellenség, akit a csapatodnak támadnia kell; a **T** célba veszi                             |
| Kór                    | Ártó hatás, például Bleeding vagy Crippled; lejár, vagy eltávolítják                           |
| Mély víz               | Víz, amelybe nem tudsz besétálni; a lövések és varázslatok átjutnak rajta                      |
| Könnyen megszakítható  | Bármely találat, amely használat közben ér, megszakítja, mint a csapdaállítást                 |
| Elit                   | Erős, arany keretes készség; sávonként egy                                                     |
| Bűbáj                  | Jó hatás, amelyet te vagy egy szövetséges varázsol                                             |
| Energia                | Amibe a legtöbb készség kerül; magától visszatöltődik                                          |
| Átok                   | Rossz hatás, amelyet egy ellenség varázsol rád                                                 |
| Jelvény                | Páncélfejlesztés: egy kis plusz egy darabon, gyakran több páncél                               |
| Megszakítás            | Egy ellenség készségének leállítása varázslás közben, vagy a támadásáé suhintás közben         |
| Leütés                 | A földre kerülés: nincs mozgás, támadás vagy varázslás                                         |
| Fenntartott            | Bűbáj, amely addig tart, amíg be nem fejezed, és közben Energiába kerül                        |
| Morál                  | Halálonként -15%, legfeljebb -60%-ig; csökkenti az Életerődet és az Energiádat                 |
| Csík                   | Egy nyíl a sávon: visszatérő vagy fogyó Életerő vagy Energia                                   |
| Elsődleges tulajdonság | Az a tulajdonság, amelyet csak az elsődleges kasztod kap, ★ jelöli                             |
| Újratöltés             | Az idő, amíg egy használt készség újra használható lesz                                        |
| Feltámasztás           | Egy halott szövetséges visszahozása                                                            |
| Rúna                   | Páncélfejlesztés: tulajdonságszintek, Életerő, Energia vagy rövidebb kórok                     |
| Sekély víz             | Víz, amelyen úgy sétálsz át, mint a szárazföldön                                               |
| Címer (pajzs)          | A jeled, egy kis pajzs a böngésződ identitásából, a neved előtt                                |
| Kezdőpont              | Ahol a csapatod a meccset kezdi                                                                |
| Érintéses készség      | A célpont megérintésével használt készség; egyes kiáltások meghiúsítják az ellenség érintéseit |
| Fegyverkészlet         | Egy fegyver és egy mellékkéz; legfeljebb négyet hordhatsz                                      |
