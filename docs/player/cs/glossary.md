# Slovníček

| Slovo                | Význam                                                                             |
| -------------------- | ---------------------------------------------------------------------------------- |
| Adrenalin            | Co některé dovednosti stojí místo energie, získává se zásahy                       |
| Prodleva po sesílání | Krátká pauza po sesílání; dovednost stisknutá v ní přijde na řadu jako další       |
| Build                | Povolání postavy, osm dovedností, atributy a vybavení                              |
| Nahlášený nepřítel   | Nepřítel, na kterého má tvůj tým útočit; **T** ho zaměří                           |
| Stav                 | Škodlivý účinek jako Bleeding nebo Crippled; vyprší nebo se odstraní               |
| Snadno přerušitelná  | Každý zásah během použití ji přeruší, například kladení pasti                      |
| Elitní               | Silná dovednost se zlatým rámečkem; jedna na lištu                                 |
| Očarování            | Dobrý účinek seslaný tebou nebo spojencem                                          |
| Energie              | Co většina dovedností stojí; sama se vrací                                         |
| Prokletí             | Špatný účinek, který na tebe sešle nepřítel                                        |
| Insignie             | Vylepšení brnění: malý bonus na jednom kusu, často víc brnění                      |
| Přerušení            | Zastavení dovednosti nepřítele během sesílání nebo jeho útoku uprostřed máchnutí   |
| Sražení              | Skácení k zemi: žádný pohyb, útok ani sesílání                                     |
| Udržované            | Očarování, které trvá, dokud ho neukončíš, a za běhu stojí energii                 |
| Morálka              | -15 % za smrt, až na -60 %; snižuje tvoje zdraví a energii                         |
| Pip                  | Jedna šipka na ukazateli: zdraví nebo energie, která se vrací nebo ubývá           |
| Primární atribut     | Atribut, který má jen tvoje primární povolání, označený ★                          |
| Obnova               | Doba, než lze použitou dovednost znovu použít                                      |
| Oživení              | Vrácení mrtvého spojence zpět                                                      |
| Runa                 | Vylepšení brnění: hodnosti atributů, zdraví, energie nebo kratší stavy             |
| Pečeť (štít)         | Tvoje značka, malý štít z identity tvého prohlížeče, před tvým jménem              |
| Startovní místo      | Kde tvůj tým začíná zápas                                                          |
| Dotyková dovednost   | Dovednost použitá dotykem cíle; některé pokřiky způsobí, že dotyky nepřátel selžou |
| Sada zbraní          | Zbraň a věc do druhé ruky; neseš až čtyři                                          |
