# ของตกแต่ง

ของตกแต่งเปลี่ยนหน้าตาของชื่อคุณและพื้นใต้เท้าคุณที่ผู้เล่นอื่นเห็น ของตกแต่งมีไว้เพื่อความสวยงามเท่านั้น: ไม่มีของตกแต่งชิ้นใดเปลี่ยนวิธีการเล่นของสิ่งใด และไม่มีชิ้นใดบังสัญญาณที่คุณอ่านในการต่อสู้ ของตกแต่งผูกกับคีย์ผู้เล่นของคุณ ตัวละครทุกตัวของคุณจึงใช้ร่วมกัน

## การได้รับ

คุณได้รับของตกแต่งจากชัยชนะจัดอันดับที่ผ่านการยืนยัน ตามที่กระดานผู้นำสาธารณะนับ
ไม่มีใครแจกให้: ใครก็ตรวจดูกระดานผู้นำและเห็นได้ว่าคุณได้รับอะไร

<!-- prettier-ignore -->
| ไอเทม | ได้รับจาก |
| --- | --- |
| กรอบหยกและฉายา ผู้ท้าชิง | ชนะจัดอันดับ 5 ครั้ง |
| ออร่ามอส, รอยมอส | ชนะจัดอันดับ 5 ครั้ง |
| กรอบกุหลาบและฉายา ทหารผ่านศึก | ชนะจัดอันดับ 25 ครั้ง |
| ออร่าถ่านไฟ, รอยถ่านไฟ | ชนะจัดอันดับ 25 ครั้ง |
| ออร่าน้ำค้างแข็ง, รอยน้ำค้างแข็ง | ชนะจัดอันดับ 75 ครั้ง |
| กรอบเขียวน้ำทะเลและฉายา ขุนศึก | ชนะจัดอันดับ 200 ครั้ง |
| ออร่าแสงดาว, รอยแสงดาว | ชนะจัดอันดับ 500 ครั้ง |
| กรอบกล้วยไม้และฉายา แชมเปี้ยน | ติดอันดับ Top 100 |
| เปลวไฟชนะติดกัน | ชนะจัดอันดับติดกัน 3 ครั้ง |

ไอเทม Top 100 และเปลวไฟจะอยู่เฉพาะตอนที่คุณยังรักษาไว้ได้ หากหลุดจาก Top 100
หรือแพ้แมตช์จัดอันดับ ไอเทมเหล่านั้นจะกลับเป็นรูปลักษณ์เริ่มต้นจนกว่าคุณจะได้รับอีกครั้ง
สิ่งที่คุณเลือกไว้ยังคงถูกเลือกอยู่

## บนพื้น

ออร่าบนพื้นคือวงแหวนจาง ๆ ที่เท้าของคุณ รอยเท้าจะทิ้งละอองเล็ก ๆ ไว้ตรงที่คุณเดิน และจางหายไปในชั่วครู่ ทั้งสองอย่างวาดอยู่ใต้วงแหวน เครื่องหมาย และสัญญาณเตือนทุกอย่าง และไม่เคยใช้สีของทีม ถ้าระบบของคุณเปิดการลดการเคลื่อนไหว ออร่าจะหยุดนิ่งและไม่มีการวาดรอยเท้า

## การสวมใส่

เปิด ตั้งค่า แล้วเลือก **ของตกแต่ง** แต่ละช่องจะแสดงไอเทมของตน
แต่ละชิ้นมีเครื่องหมายว่าใช้ได้หรือล็อกอยู่ พร้อมเงื่อนไขที่ได้รับ ตัวเลือกของคุณมีผลทันที
ผู้เล่นอื่นจะเห็นตั้งแต่ล็อบบี้ถัดไปที่คุณเข้าร่วม

## การเห็นของตกแต่งของผู้เล่นอื่น

ผู้เล่นอื่นจะเห็นของตกแต่งของคุณก็ต่อเมื่อสำเนากระดานผู้นำของเขาแสดงว่าคุณได้รับแล้ว
หากต้องการเห็นทุกคนในรูปลักษณ์เริ่มต้น ให้ปิด **แสดงของตกแต่งของผู้เล่นอื่น** ใน ตั้งค่า ใต้
**ของตกแต่ง**
