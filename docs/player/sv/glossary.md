# Ordlista

| Ord              | Betydelse                                                                                         |
| ---------------- | ------------------------------------------------------------------------------------------------- |
| Adrenalin        | Vad vissa förmågor kostar i stället för energi, vunnet genom att landa träffar                    |
| Efterkast        | Den korta pausen efter en kastning; en förmåga som trycks då går härnäst                          |
| Build            | En karaktärs yrken, åtta förmågor, attribut och utrustning                                        |
| Utpekad fiende   | Fienden ditt lag fick besked om att attackera; **T** väljer den som mål                           |
| Åkomma           | En skadlig effekt som Bleeding eller Crippled; den går över eller tas bort                        |
| Djupt vatten     | Vatten du inte kan gå ut i; skott och besvärjelser korsar det ändå                                |
| Lätt att avbryta | Varje träff som landar medan du använder den avbryter den, som att lägga en fälla                 |
| Elit             | En stark förmåga med guldram; en per rad                                                          |
| Förtrollning     | En god effekt som kastas av dig eller en allierad                                                 |
| Energi           | Vad de flesta förmågor kostar; den kommer tillbaka av sig själv                                   |
| Förbannelse      | En dålig effekt som en fiende kastar på dig                                                       |
| Insignia         | En rustningsuppgradering: lite extra på en del, ofta mer rustning                                 |
| Avbrott          | Att stoppa en fiendes förmåga medan hen kastar den, eller attacken mitt i svingen                 |
| Nedslagning      | Att kastas till marken: ingen rörelse, attack eller kastning                                      |
| Underhållen      | En förtrollning som varar tills du avslutar den och kostar energi medan den pågår                 |
| Moral            | -15 % per död, ned till -60 %; den krymper din hälsa och energi                                   |
| Pip              | En pil på en mätare: hälsa eller energi som kommer tillbaka eller rinner bort                     |
| Primärt attribut | Attributet som bara ditt primära yrke får, märkt ★                                                |
| Återladdning     | Tiden innan en använd förmåga kan användas igen                                                   |
| Återuppliva      | Att ta tillbaka en död allierad                                                                   |
| Runa             | En rustningsuppgradering: attributrang, hälsa, energi eller kortare åkommor                       |
| Grunt vatten     | Vatten du går igenom som på torra land                                                            |
| Sigill (sköld)   | Ditt märke, en liten sköld från webbläsarens identitet, framför ditt namn                         |
| Startplats       | Där ditt lag börjar matchen                                                                       |
| Beröringsförmåga | En förmåga som används genom att röra vid målet; vissa rop får fienders beröringar att misslyckas |
| Vapenset         | Ett vapen och en offhand; du bär upp till fyra                                                    |
