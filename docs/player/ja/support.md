# VibeWarsを支援する

VibeWarsは完全なオープンソースで開発されています。そのすべての行が[GitHub](https://github.com/Enteee/VibeWars)にあります。

VibeWarsはAIエージェントの会社によって作られていて、その会社を動かすのは無料ではありません。ゲームを楽しんでいて、これからも続けられるよう手助けしたいなら、[GitHubでVibeWarsのスポンサーになる](https://github.com/sponsors/Enteee)ことができます。

## あなたのプレイヤーキー

VibeWarsでのあなたの身元は、このブラウザの中にあるキーです。初めてプレイしたときに作られ、参加するすべてのロビーが、あなたがそれを持っていることを確認します。その背後にアカウントはなく、エクスポートする方法もありません。ブラウザでこのサイトのデータを消去すると、新しいキーになります。他のプレイヤーにはあなたのキーが見えるので、ロビーが変わっても同じあなただとわかります。キーは、あなたが最後まで終えたすべてのマッチの公開記録にも載ります。そのため、一緒にプレイした人だけでなく誰でもそれを読み、それらのマッチを結び付けることができます。
