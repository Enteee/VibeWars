# 치장

치장은 다른 플레이어에게 보이는 내 이름, 발밑 땅, 무기 휘두르기, 망토의 모습을 바꿔요. 오직 겉모습용이에요. 어떤 치장도 플레이 방식을 바꾸지 않고, 전투 중에 읽어야 하는 신호를 가리지도 않아요. 치장은 플레이어 키에 속하므로 모든 캐릭터가 함께 써요.

## 얻는 법

치장은 공개 리더보드가 집계하는 검증된 랭크 경기 승리로 얻어요. 누가 나눠 주는 것이 아니에요.
누구나 리더보드를 확인해서 내가 무엇을 얻었는지 볼 수 있어요.

| 아이템                          | 획득 조건            |
| ------------------------------- | -------------------- |
| --------------------------      | -------------------- |
| 비취 테두리와 도전자 칭호       | 랭크 경기 5승        |
| 이끼 오라, 이끼 흔적, 이끼 궤적 | 랭크 경기 5승        |
| 줄무늬 망토                     | 랭크 경기 5승        |

| 갈매기무늬 망토                 | 랭크 경기 25승       |
| 떠오르는 빛, 재 소멸            | 랭크 경기 25승       |

상위 100위 아이템과 불꽃은 조건을 유지하는 동안에만 남아요. 상위 100위 밖으로 밀려나거나 랭크
경기에서 지면, 다시 얻을 때까지 기본 모습으로 돌아가요. 고른 것은 그대로 선택되어 있어요.

## 바닥에

바닥 오라는 발밑의 희미한 고리예요. 발자국 흔적은 걸어간 자리에 작은 알갱이를 남기고, 금방 사라져요. 둘 다 모든 고리, 표시, 예고 아래에 그려지고 팀 색을 쓰지 않아요. 시스템에서 동작 줄이기를 켜면 오라는 멈춰 있고 흔적은 그려지지 않아요.

## 무기와 망토에

무기 궤적은 근접 공격이 적중할 때 무기 뒤에 남는 가는 리본으로, 4분의 1초 안에 사라져요. 활, 창, 완드, 지팡이에는 생기지 않고, 어떤 주문이나 시전에도 나타나지 않아요. 망토 무늬는 길드 망토에 줄무늬, 갈매기무늬, 사분할 또는 별을 망토 자체의 테두리 색으로 그려요. 문장은 항상 맨 위에 남아 민무늬 망토에서처럼 또렷해요. 옵션의 망토 디자이너는 무늬가 들어간 망토를 펼친 모습으로 보여 줘요. 시스템에서 동작 줄이기를 켜면 무기 궤적은 그려지지 않아요.

## 돌아올 때와 쓰러질 때

등장 스타일은 등장하거나 부활할 때 발밑에 작은 알갱이를 모아요. 사망 소멸은 쓰러질 때 그것들을 흩어 놓아요. 둘 다 기본 복귀와 쓰러짐과 정확히 같은 시간 동안 이어지고, 몸 아래에 그려지며, 윤곽선, 팀 고리, 시체를 언제나처럼 알아보기 쉽게 남겨 둬요. 시스템에서 동작 줄이기를 켜면 기본 페이드만 그려져요.

## 착용하는 법

옵션을 열고 **치장**을 고르세요. 슬롯마다 아이템이 나열되고, 각각 착용 가능인지 잠김인지와 획득
조건이 표시돼요. 선택은 바로 적용돼요. 다른 플레이어는 다음에 들어가는 로비부터 보게 돼요.

## 다른 플레이어의 치장 보기

다른 플레이어는 자신이 가진 리더보드 사본에 내가 치장을 얻은 것으로 나와 있을 때만 내 치장을
봐요. 모두를 기본 모습으로 보려면 옵션의 **치장**에서 **다른 플레이어의 치장 표시**를 끄세요.
