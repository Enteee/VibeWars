# Ordliste

| Ord             | Betydning                                                                                 |
| --------------- | ----------------------------------------------------------------------------------------- |
| Adrenalin       | Det, nogle evner koster i stedet for energi; du vinder det ved at ramme                   |
| Efterkast       | Den korte pause efter et kast; en evne, du trykker på i den, kommer bagefter              |
| Build           | En figurs klasser, otte evner, attributter og udstyr                                      |
| Udpeget fjende  | Den fjende, dit hold fik besked på at angribe; **T** vælger den                           |
| Tilstand        | En skadelig effekt som Bleeding eller Crippled; den fortager sig eller fjernes            |
| Dybt vand       | Vand, du ikke kan gå ud i; skud og besværgelser kan stadig krydse det                     |
| Let at afbryde  | Ethvert slag, der rammer, mens du bruger den, afbryder den, fx når du sætter en fælde     |
| Elite           | En stærk evne med guldramme; én pr. bjælke                                                |
| Fortryllelse    | En god effekt kastet af dig eller en allieret                                             |
| Energi          | Det, de fleste evner koster; den kommer tilbage af sig selv                               |
| Forbandelse     | En dårlig effekt, som en fjende kaster på dig                                             |
| Insignie        | En rustningsopgradering: lidt ekstra på én del, ofte mere rustning                        |
| Afbrydelse      | At stoppe en fjendes evne, mens den kastes, eller deres angreb midt i svinget             |
| Væltet          | At blive kastet til jorden: ingen bevægelse, ingen angreb og ingen kast                   |
| Vedligeholdt    | En fortryllelse, der varer, til du afslutter den, og koster energi, mens den kører        |
| Moral           | -15 % pr. død, ned til -60 %; den mindsker dit liv og din energi                          |
| Pip             | En pil på en bjælke: liv eller energi, der kommer tilbage eller drænes                    |
| Primær attribut | Den attribut, kun din primære klasse får, markeret ★                                      |
| Genopladning    | Tiden, før en brugt evne kan bruges igen                                                  |
| Genoplive       | At bringe en død allieret tilbage                                                         |
| Rune            | En rustningsopgradering: attributrang, liv, energi eller kortere tilstande                |
| Lavt vand       | Vand, du går igennem som på tørt land                                                     |
| Signet (skjold) | Dit mærke, et lille skjold ud fra din browsers identitet, foran dit navn                  |
| Startområde     | Hvor dit hold starter kampen                                                              |
| Berøringsevne   | En evne, der bruges ved at røre målet; nogle råb får fjenders berøringer til at mislykkes |
| Våbensæt        | Et våben og en sekundærhånd; du har op til fire med                                       |
