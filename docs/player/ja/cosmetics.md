# コスメティック

コスメティックは、他のプレイヤーから見たあなたの名前の見た目を変えます。見た目だけのもので、どのコスメティックもゲームの挙動を変えることはなく、戦闘中に読み取る合図を隠すこともありません。コスメティックはプレイヤーキーに紐づくので、あなたのすべてのキャラクターで共有されます。

## 獲得する

コスメティックは、公開ランキングが数える検証済みのランク戦の勝利で獲得します。誰かが配るものではありません。誰でもランキングを確認して、あなたが何を獲得したかを見ることができます。

| アイテム                           | 獲得条件      |
| ---------------------------------- | ------------- |
| 翡翠のフレームと称号「挑戦者」     | ランク戦5勝   |
| 薔薇のフレームと称号「ベテラン」   | ランク戦25勝  |
| 青緑のフレームと称号「将軍」       | ランク戦200勝 |
| 蘭のフレームと称号「チャンピオン」 | トップ100入り |
| 連勝の炎                           | ランク戦3連勝 |

トップ100のアイテムと炎は、条件を満たしている間だけ有効です。トップ100から外れるか、ランク戦で負けると、再び獲得するまでデフォルトの見た目に戻ります。選んだものは選んだままです。

## 身につける

オプションを開いて **コスメティック** を選びます。各スロットにはアイテムが並び、それぞれ装着可能かロック中かと、獲得条件が表示されます。選択はすぐに反映されます。他のプレイヤーには、次に参加するロビーから表示されます。

## 他のプレイヤーのコスメティックを見る

他のプレイヤーにあなたのコスメティックが見えるのは、その人の手元のランキングで、あなたが獲得したことが確認できる場合だけです。全員をデフォルトの見た目で表示するには、オプションの **コスメティック** で **他のプレイヤーのコスメティックを表示** をオフにします。
