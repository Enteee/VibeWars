# พื้นฐานการต่อสู้

## พลังชีวิตและพลังงาน

คุณเริ่มด้วย **พลังชีวิต** 500 และ **พลังงาน** 50 รูนและขวัญกำลังใจเปลี่ยนค่าทั้งสองได้
สกิลใช้พลังงาน และพลังงานจะฟื้นขึ้นเองอย่างช้าๆ Warrior
และ Paragon ฟื้นช้าที่สุด Ranger เร็วขึ้นหน่อย ส่วนคนอื่นๆ ฟื้นเร็วที่สุด

ลูกศรบนแถบของคุณคือ **pip**: แต่ละอันคือพลังชีวิตหรือพลังงานที่กำลังฟื้นกลับ
หรือกำลังลดลง ทีละนิดทุกวินาที Bleeding, Burning และ
Poison ทำให้พลังชีวิตลดลง Regeneration และเวทรักษาเพิ่มพลังชีวิต
เมื่อออกจากการต่อสู้ครบ 5 วินาที พลังชีวิตของคุณจะเริ่มฟื้นเอง และยิ่งอยู่นอกการต่อสู้นานก็ยิ่งฟื้นเร็วขึ้น

## อะดรีนาลีน

Warrior, Paragon และอาชีพอื่นๆ มีสกิลที่ใช้ **อะดรีนาลีน**
แทนพลังงาน แต่ละสกิลแบบนี้ชาร์จแยกกัน: การโจมตีด้วยอาวุธที่โดนแต่ละครั้ง
ให้หนึ่งขีดแก่ทุกสกิลเหล่านั้น และการโดนตีแรงๆ ก็เช่นกัน
การใช้สกิลหนึ่งจะทำให้สกิลนั้นว่างเปล่า และลดหนึ่งขีดจากสกิลอื่นๆ
เมื่อออกจากการต่อสู้ครบ 25 วินาที ทุกสกิลจะว่างเปล่า

## การใช้สกิล

สกิลอาจต้องใช้เวลาชั่วครู่ในการ **ร่าย** แล้วต้องรอ
**คูลดาวน์** ก่อนจะใช้ได้อีกครั้ง ถ้าเป้าหมายอยู่นอกระยะ
คุณจะเดินเข้าไปหาก่อน การเคลื่อนที่หรือ Esc จะยกเลิกการร่าย: พลังงานเสียไปแล้ว
แต่สกิลจะไม่เข้าคูลดาวน์ หลังสกิลใดๆ ที่มีเวลาร่าย ยกเว้น
สกิลโจมตี จะมีช่วงหยุดสั้นๆ ที่คุณทำอะไรไม่ได้

สกิลที่คุณกดขณะกำลังใช้สกิลอื่นอยู่ หรือในช่วงหยุดนั้น จะ **เข้าคิว**:
มันจะทำงานเป็นลำดับถัดไป และช่องของมันจะกะพริบจนกว่าจะได้ทำงาน รอได้แค่สกิลเดียว
การกดสกิลอื่นจะแทนที่มัน การเคลื่อนที่, Esc, การถูกขัดจังหวะหรือการถูกล้มจะยกเลิกมัน

**เสียงตะโกนและท่าทาง** ไม่เข้าคิวเลย: มันทำงานทันที แม้ขณะที่คุณ
ร่ายสกิลอื่น อยู่ในช่วงหยุดนั้น หรือถูกล้มอยู่ การร่ายก็ยังดำเนินต่อ
เมื่อใช้แบบนี้ มันจะไม่พาคุณเดินเข้าไป: ถ้าอยู่นอกระยะ มันจะถูกปฏิเสธ

## การขัดจังหวะและการล้ม

**การขัดจังหวะ** หยุดสกิลของศัตรูขณะที่พวกเขากำลังร่าย
พลังงานของพวกเขาเสียไปและสกิลเข้าคูลดาวน์ การขัดจังหวะบางอย่างยังล็อก
สกิลนั้นไว้ชั่วขณะด้วย ขัดจังหวะเร็วไปหรือช้าไปจะไม่เกิดอะไรขึ้น

แต่ละอาชีพมีเสียงใช้สกิลเป็นของตัวเอง ฟังเสียงของเป้าหมายของคุณ

การขัดจังหวะส่วนใหญ่ยังหยุดการโจมตีธรรมดากลางการเหวี่ยงได้ด้วย: การโจมตีครั้งนั้นจะไม่โดน
และการเหวี่ยงจะเริ่มใหม่ ศัตรูที่ยังเดินเข้าหาเป้าหมายอยู่
ไม่มีอะไรให้ขัดจังหวะ การขัดจังหวะที่การ์ดเขียนว่า "a skill" หรือ "a
spell" จะไม่ยุ่งกับการโจมตีธรรมดา

ท่าทางบางอย่าง เช่น Mantra of Concentration จะหยุดการขัดจังหวะที่เล็งมา
ที่คุณ ไม่มีท่าทางไหนหยุดการล้มได้

เมื่อ **ถูกล้ม** คุณจะเคลื่อนที่ โจมตี หรือใช้สกิลไม่ได้ชั่วขณะ
ยกเว้นเสียงตะโกนหรือท่าทาง และการร่ายที่กำลังทำอยู่จะล้มเหลว

## สภาวะผิดปกติ คำสาป และมนตร์เสริม

**สภาวะผิดปกติ** ทำร้ายคุณจนกว่าจะหมดเวลาหรือถูกลบออก:

<!-- prettier-ignore -->
| สภาวะผิดปกติ | ผลของมัน |
| --- | --- |
| Bleeding | ลดพลังชีวิต |
| Burning | ลดพลังชีวิตอย่างรวดเร็ว |
| Poison | ลดพลังชีวิต |
| Disease | ลดพลังชีวิต และแพร่ไปยังทุกคนที่อยู่ข้างคุณ |
| Crippled | คุณเคลื่อนที่ด้วยความเร็วครึ่งเดียว |
| Blind | การโจมตีส่วนใหญ่ของคุณพลาด |
| Weakness | อาวุธของคุณตีเบาลงมาก |
| Cracked Armor | เกราะลดลง |
| Deep Wound | พลังชีวิตสูงสุดลดลง และการรักษาได้ผลน้อยลง |
| Dazed | ร่ายเวทช้าลง การโจมตีใดๆ ก็ขัดจังหวะได้ |

**คำสาป** ถูกร่ายใส่คุณโดยศัตรู **มนตร์เสริม** ถูกร่ายโดยตัวคุณเองหรือพันธมิตร
แต่ละอย่างถูกลบออกได้ด้วยสกิลประเภทของมันเอง มนตร์เสริมบางอย่าง
**ต่อเนื่อง**: มันอยู่จนกว่าคุณจะยกเลิก โดยใช้พลังงานหนึ่ง pip ขณะ
ทำงาน ดับเบิลคลิกไอคอนของมันเพื่อยกเลิก

สกิลไม่กี่สกิลจะหยุดทำงานขณะที่คุณมีมนตร์เสริม และทำงานอีกครั้งเมื่อ
คุณไม่มีแล้ว สกิลที่อยู่ได้ "next N attacks" นับทุก
การโจมตี ดังนั้นการพลาดหรือการถูกบล็อกก็ใช้ไปหนึ่งครั้งเหมือนการโจมตีที่โดน

## เกราะและความเสียหาย

Warrior และ Paragon สวมเกราะมากที่สุด Ranger, Assassin และ
Dervish น้อยกว่า ส่วนสายร่ายเวทน้อยที่สุด เกราะลดความเสียหายจากอาวุธ ธาตุ chaos
และ dark ความเสียหาย holy, shadow และไม่มีประเภท การดูดพลังชีวิต และการขโมย
พลังชีวิต ไม่สนเกราะ เฉพาะการโจมตีด้วยอาวุธเท่านั้นที่ติดคริติคอลได้
มนตร์เสริมบางอย่างทำให้ผู้ที่มีมันไม่โดนคริติคอล

## ความตาย การชุบชีวิต และขวัญกำลังใจ

ในโหมดส่วนใหญ่ คนตายจะนอนอยู่อย่างนั้นจนกว่าพันธมิตรจะ **ชุบชีวิต** ด้วย
สกิล เช่น Resurrection Signet ซึ่งใครก็เอาไปได้ บางโหมด
ให้คนตายกลับมาเป็นระลอก หรือกลับมาเอง ดู[โหมด](modes.md)

ทุกการตายทำให้คุณเสีย **ขวัญกำลังใจ** 15% ลงไปได้ถึง -60%: พลังชีวิตสูงสุด
และพลังงานสูงสุดของคุณจะลดลงตามไปด้วย ศัตรูแต่ละตัวที่ทีมของคุณฆ่าได้จะคืนให้ 2%
ขึ้นไปได้ถึง 0 ในศึกกิลด์ การครองแท่นธงจะยกมันขึ้นไปเกินกว่านั้น
ได้ถึง +10%
