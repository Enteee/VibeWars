# Glossar

| Begriff              | Bedeutung                                                                            |
| -------------------- | ------------------------------------------------------------------------------------ |
| Adrenalin            | Was manche Skills statt Energie kosten; du bekommst es durch Treffer                 |
| Nachwirkzeit         | Die kurze Pause nach dem Wirken; ein Skill, den du darin drückst, kommt als Nächstes |
| Build                | Die Klassen, acht Skills, Attribute und Ausrüstung eines Charakters                  |
| Angesagter Gegner    | Der Gegner, den dein Team angreifen soll; **T** visiert ihn an                       |
| Zustand              | Eine schädliche Wirkung wie Bleeding oder Crippled; sie läuft aus oder wird entfernt |
| Leicht unterbrechbar | Jeder Treffer während der Nutzung unterbricht sie, etwa beim Legen einer Falle       |
| Elite                | Ein starker Skill mit goldenem Rahmen; einer pro Leiste                              |
| Verzauberung         | Eine gute Wirkung, von dir oder einem Verbündeten gewirkt                            |
| Energie              | Was die meisten Skills kosten; sie kommt von selbst zurück                           |
| Verhexung            | Eine schlechte Wirkung, die ein Gegner auf dich wirkt                                |
| Insignie             | Ein Rüstungs-Upgrade: ein kleines Extra auf einem Teil, oft mehr Rüstung             |
| Unterbrechung        | Den Skill eines Gegners beim Wirken stoppen oder seinen Angriff mitten im Schlag     |
| Niederwurf           | Du wirst zu Boden geworfen: kein Laufen, Angreifen oder Wirken                       |
| Aufrechterhalten     | Eine Verzauberung, die bleibt, bis du sie beendest, und solange Energie kostet       |
| Moral                | -15 % pro Tod, bis -60 %; sie senkt dein Leben und deine Energie                     |
| Pip                  | Ein Pfeil auf einer Leiste: Leben oder Energie, die zurückkommen oder abfließen      |
| Primärattribut       | Das Attribut, das nur deine Primärklasse bekommt, markiert mit ★                     |
| Aufladung            | Die Zeit, bis ein benutzter Skill wieder nutzbar ist                                 |
| Wiederbeleben        | Einen toten Verbündeten zurückholen                                                  |
| Rune                 | Ein Rüstungs-Upgrade: Attributränge, Leben, Energie oder kürzere Zustände            |
| Siegel (Schild)      | Dein Zeichen, ein kleines Schild aus deiner Browser-Identität, vor deinem Namen      |
| Spawn                | Wo dein Team das Match beginnt                                                       |
| Berührungs-Skill     | Ein Skill, der das Ziel berühren muss; manche Schreie lassen Berührungen scheitern   |
| Waffenset            | Eine Waffe und eine Zweithand; du trägst bis zu vier                                 |
