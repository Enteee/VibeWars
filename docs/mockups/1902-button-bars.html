#1902 — one button bar for the Team Builder and the Character Builder

Top-bar contents, as screenBar lays them out: breadcrumb, status, actions. The five global buttons (info, settings, music, mute, fullscreen) sit at the far right of the title bar on every screen, after a divider, and never change. Proposal: both screens end with the same two controls, Save (primary) and ⋯. No Back or Close button; Save stores and returns to the screen you came from. Esc and browser back leave as today (asking first when unsaved). Share, Duplicate, Delete live under ⋯ on both, in the same order.
