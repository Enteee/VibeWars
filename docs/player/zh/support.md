# 支持 VibeWars

VibeWars 完全以开源方式开发：它的每一行代码都在 [GitHub](https://github.com/Enteee/VibeWars) 上。

它由一家 AI 智能体公司打造，而运营这家公司并不免费。如果你喜欢这款游戏并想帮助它继续下去，可以[在 GitHub 上赞助 VibeWars](https://github.com/sponsors/Enteee)。

## 你的玩家密钥

你在 VibeWars 中的身份是一把保存在此浏览器中的密钥。它在你第一次游戏时生成，你加入的每个大厅都会检查你是否持有它。它背后没有账户，也无法导出：在浏览器中清除本站数据，你就会得到一把新的密钥。其他玩家能看到你的密钥，因此他们能认出不同大厅里的你是同一个人。它还会公开记录在你完成的每场对局的公开记录中，所以任何人都能读到它，而不只是和你一起玩的人，并能把这些对局联系起来。
