# Kosmetiikka

Kosmetiikka muuttaa sitä, miltä nimesi ja maa allasi näyttävät muille pelaajille. Se on pelkkää ulkonäköä: mikään kosmetiikka ei muuta sitä, miten mikään pelaa, eikä mikään koskaan peitä vihjettä, jota luet taistelussa. Se kuuluu pelaaja-avaimellesi, joten kaikki hahmosi jakavat sen.

## Ansaitseminen

Ansaitset kosmetiikkaa vahvistetuilla rankatuilla voitoilla, sellaisina kuin julkinen tulostaulu
ne laskee. Kukaan ei jaa niitä: kuka tahansa voi tarkistaa tulostaulun ja nähdä, mitä olet
ansainnut.

| Esine                                  | Miten ansaitaan               |
| -------------------------------------- | ----------------------------- |
| Jadekehys ja arvonimi Haastaja         | 5 rankattua voittoa           |
| Sammalaura, Sammaljälki                | 5 rankattua voittoa           |
| Ruusukehys ja arvonimi Veteraani       | 25 rankattua voittoa          |
| Hiillosaura, Hiillosjälki              | 25 rankattua voittoa          |
| Huurreaura, Huurrejälki                | 75 rankattua voittoa          |
| Sinivihreä kehys ja arvonimi Sotaherra | 200 rankattua voittoa         |
| Tähtivaloaura, Tähtivalojälki          | 500 rankattua voittoa         |
| Orkideakehys ja arvonimi Mestari       | Sija Top 100:ssa              |
| Voittoputken liekki                    | 3 rankattua voittoa peräkkäin |

Top 100:n esineet ja liekki säilyvät vain niin kauan kuin pidät ne. Jos putoat Top 100:sta tai
häviät rankatun ottelun, ne palaavat oletusulkoasuun, kunnes ansaitset ne uudelleen. Valintasi
pysyy valittuna.

## Maassa

Maa-aura on himmeä rengas jalkojesi juuressa. Askeljälki jättää kulkemaasi kohtaan pieniä hiukkasia, jotka häviävät hetkessä. Molemmat piirretään jokaisen renkaan, merkin ja varoituksen alle, eikä kumpikaan ole koskaan joukkueen värinen. Jos järjestelmässäsi on vähennetty liike päällä, aura pysyy paikallaan eikä jälkeä piirretä.

## Käyttäminen

Avaa Asetukset ja valitse **Kosmetiikka**. Jokainen paikka luettelee esineensä, kukin merkittynä
käytettäväksi tai lukituksi, sekä sen, millä sen ansaitsee. Valintasi tulee voimaan heti. Muut
pelaajat näkevät sen seuraavasta aulasta alkaen, johon liityt.

## Muiden pelaajien kosmetiikan näkeminen

Muut pelaajat näkevät kosmetiikkasi vain, jos heidän kopionsa tulostaulusta näyttää, että olet
ansainnut sen. Jos haluat nähdä kaikki oletusulkoasussa, kytke **Näytä muiden pelaajien
kosmetiikka** pois Asetuksista kohdasta **Kosmetiikka**.
