# ボット

**ボット**は、ゲームが代わりにプレイするプレイヤーです。あなたがホストするロビーでは、誰も入らなかった枠をすべてボットがプレイするので、練習したり、少ない人数の友達と遊んだりできます。

## 誰がボットをプレイするか

ボットを追加する人はいません。ロビーには人だけが並びます。[チームロビー](modes.md#チームロビー)が終わると、各チームは選んだチームビルドでプレイし、そのキャラクターのうち誰も確保しなかったものはすべて、そのキャラクターの名前でボットがプレイします。誰もいないチームは、ランダムなプリセットのチームを全員ボットでプレイします。チームロビーの間に抜けた人のキャラクターは、ボットに引き継がれます。

ロビーとチームロビーでは、ボットはほかの人と同じように見えます。マッチでは、ネームプレート、ターゲットフレーム、パーティーウィンドウ、マッチの概要で**BOT**のタグが付きます。

ボットは1つのマッチのために作られます。マッチが終わると、ロビーには再び人が並び、次のマッチのボットは新しく作られます。

## ボットの戦い方

ボットは、ビルドが与える役割をこなします。近接武器を持つボットは**前衛**です。接近してターゲットを攻撃します。味方にかけられる回復や防御を2つ以上持つボットは**ヒーラー**です。最も傷ついている味方の後ろに、敵から離れて立ちます。2人以上の敵が1人の味方に集中すると、ヒーラーは攻撃が当たる前にその味方に防御をかけます。それ以外のボットはすべて**遠距離**です。自分のすべての攻撃が届く位置を保ち、近づきすぎた敵には立ち止まって戦います。遠距離のボットとヒーラーは、届く敵が少ない場所へ移動し、柱を遮蔽物として使います。チームは、届く範囲でヘルスが60%を下回った敵に向かい、とどめを刺します。King of the Hillでは、あなたのチームが祭壇を確保していない間は、祭壇の上にいる相手チームのゴーストヒーローがそれよりも優先されます。チームより大きく先行したボットは、さらに進む前に残りを待ちます。

ボットのダメージ役は、大きな一撃（攻撃スキルとダメージスペル）を温存し、チームのターゲットにまとめて放ちます。そうすれば、ダメージが少しずつ入ってヒーラーに回復されることなく、一度に入ります。最も遅いスペルが最初に、より速いものはその速さの分だけ後に放たれます。その間も、攻撃を振り続け、呪いや状態異常をかけ続けます。ボットはチームメイトを最大4秒しか待たず、ヘルスが30%を下回った敵にとどめを刺すときはまったく待ちません。ターゲットがProtective SpiritやAegisのような防御のエンチャントを受けているときは、Strip Enchantmentのようなエンチャント除去を持つボットがまずそれを外し、ほかのボットはそのために攻撃を控えます。

ひどく傷つき、戦いに負けつつあるボットは、ヒーラーの後ろか拠点まで下がり、ヘルスの大半が戻るまで手の届かないところで休みます。

ボットが倒れた味方を蘇生させるのは、敵がその体のすぐそばにおらず、近くに立っている自チームの人数が相手より多く、かつ近くの敵がそのボット自身をターゲットにしていないときだけです。

ボットは、Fireballや攻撃スキルの矢のように自分を狙ったスキルショットの約半分をよけます。そのため、止まったり向きを変えたりすることは、あなたに対してと同じようにボットにも有効です。

ボットは、遠回りがそれほど長くなければ燃える地面などの有害な場所を避けて歩き、その中に立っていれば外へ出ます。

中断を持つボットは、重要な詠唱のためにそれを取っておきます。最優先は蘇生と祭壇を確保しようとするゴーストヒーロー、次に回復や防御、エリートスキル、攻撃スキルやダメージスペルのような大きな一撃です。それ以外のすべてと通常の武器攻撃は見逃します。プレイヤーと同じく、そうした詠唱の約4回に1回は中断に失敗します。

ボットは、起きたことに反応するのに人間のような一瞬（1秒に満たない時間）をかけます。そのため、素早い中断や遅めの回避がボットを出し抜くことがあります。

3チームの戦いでは、ボットは一度に1つの敵チームと戦います。自分たちを攻撃しているチーム、誰も攻撃していないときは届く範囲で最も傷ついているチームです。ほかのチームが明らかに多くのプレイヤーを自分たちに向けるまでそのチームと戦い続け、別のチームに攻撃されている間は新しいチームに突撃しません。チームがコールしたターゲットは、どのチームにいても最優先です。数えるのはプレイヤーだけです。チームのゴーストや衛兵が近くに立っていても、ボットはそのチームに向かいません。

## ランダムアリーナ

ランダムアリーナにはボットはいません。すべての枠が本物のプレイヤーで、十分な人数がキューに入るまで待ちます。
