# Maps are 2.5D, lit and beautiful

The operator played Training Wilds and called it terrible: working ground
effects drawn as flat placeholders. Working is not done.

- A map you touch follows the 2.5D style (#2810): heights, walls, light
  sources and shadow, like the best existing 2.5D maps.
- Each element looks like what it is: lava glows and flows and casts light,
  fog drifts, mire is mud. A coloured rectangle is a placeholder, not a
  finished card.
- Gameplay stays readable: zones remain identifiable at a glance.
- QA checks the look in the browser before merging, not only the tests.
  Ask asset-designer when art is missing.
- Architects: put this in every map or world-element spec.
