# Γλωσσάρι

| Λέξη                 | Σημασία                                                                                                            |
| -------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Αδρεναλίνη           | Αυτό που κοστίζουν κάποιες ικανότητες αντί για Ενέργεια· την κερδίζεις πετυχαίνοντας χτυπήματα                     |
| Παύση μετά τη ρίψη   | Η μικρή παύση μετά από μια ρίψη· μια ικανότητα που πατάς τότε πάει επόμενη                                         |
| Σύνθεση              | Τα επαγγέλματα ενός χαρακτήρα, οι οκτώ ικανότητες, τα χαρακτηριστικά και ο εξοπλισμός του                          |
| Ανακοινωμένος εχθρός | Ο εχθρός που ειπώθηκε στην ομάδα σου να χτυπήσει· το **T** τον στοχεύει                                            |
| Πάθηση               | Βλαβερή επίδραση όπως το Bleeding ή το Crippled· λήγει ή αφαιρείται                                                |
| Βαθύ νερό            | Νερό όπου δεν μπορείς να μπεις· οι βολές και τα ξόρκια το περνούν                                                  |
| Εύκολα διακόψιμη     | Όποιο χτύπημα σε βρει όσο τη χρησιμοποιείς τη διακόπτει, όπως όταν στήνεις παγίδα                                  |
| Ελίτ                 | Δυνατή ικανότητα με χρυσό πλαίσιο· μία ανά μπάρα                                                                   |
| Μάγεμα               | Καλή επίδραση που ρίχνεις εσύ ή ένας σύμμαχος                                                                      |
| Ενέργεια             | Αυτό που κοστίζουν οι περισσότερες ικανότητες· αναπληρώνεται μόνη της                                              |
| Κατάρα               | Κακή επίδραση που σου ρίχνει ένας εχθρός                                                                           |
| Διακριτικό           | Αναβάθμιση πανοπλίας: κάτι μικρό επιπλέον σε ένα κομμάτι, συχνά περισσότερη πανοπλία                               |
| Διακοπή              | Σταματάς την ικανότητα ενός εχθρού την ώρα που τη ρίχνει, ή την επίθεσή του στη μέση της κίνησης                   |
| Ανατροπή             | Πέφτεις στο έδαφος: δεν κινείσαι, δεν επιτίθεσαι και δεν ρίχνεις τίποτα                                            |
| Συντηρούμενο         | Μάγεμα που κρατά μέχρι να το τελειώσεις, και κοστίζει Ενέργεια όσο είναι ενεργό                                    |
| Ηθικό                | -15% ανά θάνατο, έως το -60%· μικραίνει την Υγεία και την Ενέργειά σου                                             |
| Pip                  | Ένα βελάκι σε μια μπάρα: Υγεία ή Ενέργεια που αναπληρώνεται ή χάνεται                                              |
| Κύριο χαρακτηριστικό | Το χαρακτηριστικό που παίρνει μόνο το κύριο επάγγελμά σου, σημειωμένο με ★                                         |
| Επαναφόρτιση         | Ο χρόνος μέχρι να μπορεί να ξαναχρησιμοποιηθεί μια ικανότητα                                                       |
| Ανάσταση             | Φέρνεις πίσω έναν νεκρό σύμμαχο                                                                                    |
| Ρούνος               | Αναβάθμιση πανοπλίας: επίπεδα χαρακτηριστικού, Υγεία, Ενέργεια ή πιο σύντομες παθήσεις                             |
| Ρηχό νερό            | Νερό που το διασχίζεις σαν στεγνό έδαφος                                                                           |
| Σφραγίδα (ασπίδα)    | Το σημάδι σου, μια μικρή ασπίδα από την ταυτότητα του φυλλομετρητή σου, μπροστά από το όνομά σου                   |
| Σημείο εκκίνησης     | Εκεί όπου ξεκινά η ομάδα σου τον αγώνα                                                                             |
| Ικανότητα αφής       | Ικανότητα που χρησιμοποιείται αγγίζοντας τον στόχο· κάποιες κραυγές κάνουν τα αγγίγματα των εχθρών να αποτυγχάνουν |
| Σετ όπλων            | Ένα όπλο και ένα δεύτερο χέρι· κουβαλάς έως τέσσερα                                                                |
