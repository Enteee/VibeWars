# 装扮

装扮会改变其他玩家眼中你名字和你脚下地面的样子。它们纯粹是外观：没有任何装扮会改变任何东西的玩法，也不会遮住你在战斗中需要读取的提示。装扮属于你的玩家密钥，因此你所有的角色共享它们。

## 获取

你通过经过验证的排位赛胜利获得装扮，以公开排行榜的统计为准。没有人会发放它们：任何人都可以查看排行榜，看到你获得了什么。

| 物品                   | 获取方式         |
| ---------------------- | ---------------- |
| 翡翠边框和“挑战者”称号 | 5 场排位赛胜利   |
| 苔藓光环、苔藓足迹     | 5 场排位赛胜利   |
| 玫瑰边框和“老兵”称号   | 25 场排位赛胜利  |
| 余烬光环、余烬足迹     | 25 场排位赛胜利  |
| 霜冻光环、霜冻足迹     | 75 场排位赛胜利  |
| 青绿边框和“军阀”称号   | 200 场排位赛胜利 |
| 星光光环、星光足迹     | 500 场排位赛胜利 |
| 兰紫边框和“冠军”称号   | 进入前 100 名    |
| 连胜火焰               | 排位赛 3 连胜    |

前 100 名物品和火焰只在你保持条件时有效。跌出前 100 名，或输掉一场排位赛，它们就会恢复为默认外观，直到你再次获得。你的选择会保持不变。

## 地面上

地面光环是你脚下一圈淡淡的光环。足迹会在你走过的地方留下细小的光点，转眼便会消失。两者都画在每个光圈、标记和预警之下，也从不使用队伍颜色。如果你的系统开启了减弱动态效果，光环会静止不动，也不会画出足迹。

## 佩戴

打开选项并选择 **装扮**。每个栏位列出其物品，每件都标明可佩戴或未解锁，以及获取方式。你的选择会立即生效。其他玩家会从你加入的下一个大厅开始看到它。

## 查看其他玩家的装扮

只有当其他玩家手中的排行榜副本显示你已获得装扮时，他们才会看到你的装扮。要让所有人都显示为默认外观，请在选项的 **装扮** 中关闭 **显示其他玩家的装扮**。
