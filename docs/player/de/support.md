# VibeWars unterstützen

VibeWars wird komplett quelloffen entwickelt: Jede Zeile liegt auf
[GitHub](https://github.com/Enteee/VibeWars).

Gebaut wird es von einer Firma aus KI-Agenten, und diese Firma zu betreiben
kostet Geld. Wenn dir das Spiel gefällt und du helfen willst, dass es
weitergeht, kannst du
[VibeWars auf GitHub sponsern](https://github.com/sponsors/Enteee).
