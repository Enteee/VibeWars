# 戦闘の基本

## ヘルスとエナジー

あなたは500の**ヘルス**と50の**エナジー**で始まります。ルーンとモラルは両方を変化させます。スキルはエナジーを消費し、エナジーはゆっくりと自然に回復します。WarriorとParagonは回復が最も遅く、Rangerは少し速く、それ以外の全員が最も速く回復します。

バーの矢印は**ピップ**です。1つ1つが、毎秒少しずつ回復していく、または減っていくヘルスやエナジーを表します。Bleeding、Burning、Poisonはヘルスを減らし、Regenerationや回復スペルはヘルスを増やします。5秒間戦闘から離れていると、ヘルスは自然に回復し始め、離れている時間が長いほど速くなります。

## アドレナリン

Warrior、Paragonなどは、エナジーの代わりに**アドレナリン**を消費するスキルを持っています。そのようなスキルはそれぞれ個別にチャージされます。武器による攻撃を当てるたびに、そのすべてに1ストライクずつ加わり、大きな一撃を受けたときも同様です。1つを使うと、それは空になり、ほかのスキルから1ストライクずつ減ります。25秒間戦闘から離れていると、すべて空になります。

## スキルを使う

スキルは**詠唱**に少し時間がかかることがあり、その後、再び使えるようになるまで**リチャージ**の時間が必要です。ターゲットが射程外なら、まずそこへ歩いていきます。移動するかEscを押すと詠唱はキャンセルされます。エナジーは失われますが、スキルはリチャージに入りません。詠唱時間のあるスキルの後には、攻撃スキルを除き、何もできない短い間があります。

別のスキルを使っている最中やその間に押したスキルは、**予約**されます。それが次に発動し、発動するまでそのスロットが脈打ちます。待てるのは1つだけで、別のスキルを押すとそれに置き換わります。移動、Esc、中断、ダウンで予約は取り消されます。

**シャウトとスタンス**は予約されません。別のスキルを詠唱中でも、その間でも、ダウン中でも、すぐに発動します。詠唱はそのまま続きます。このように使った場合は、射程まで歩いていくことはなく、射程外なら使用を拒否されます。

## 中断とダウン

**中断**は、敵が詠唱している最中のスキルを止めます。敵のエナジーは消費され、スキルはリチャージに入ります。中断の中には、しばらくそのスキルを使えなくするものもあります。中断が早すぎても遅すぎても、何も起きません。

ほとんどの中断は、振りかぶった通常攻撃も止めます。その一撃は当たらず、振りはやり直しになります。まだターゲットに向かって歩いている敵には、中断するものがありません。カードに「スキル」や「スペル」と書かれた中断は、通常攻撃には効きません。

Mantra of Concentrationなど一部のスタンスは、あなたに向けられた中断を防ぎます。ダウンを防ぐスタンスはありません。

**ダウン**すると、しばらく移動も攻撃もスキルの使用もできません。ただしシャウトとスタンスは例外です。進行中の詠唱は失敗します。

## 状態異常、呪い、エンチャント

**状態異常**は、時間切れになるか除去されるまであなたを苦しめます。

| 状態異常      | 効果                                             |
| ------------- | ------------------------------------------------ |
| Bleeding      | ヘルスが減る                                     |
| Burning       | ヘルスが速く減る                                 |
| Poison        | ヘルスが減る                                     |
| Disease       | ヘルスが減り、隣にいる人にうつる                 |
| Crippled      | 移動速度が半分になる                             |
| Blind         | 攻撃のほとんどが外れる                           |
| Weakness      | 武器の攻撃がかなり弱くなる                       |
| Cracked Armor | 防御力が下がる                                   |
| Deep Wound    | 最大ヘルスが下がり、回復の効果も下がる           |
| Dazed         | スペルの詠唱が遅くなり、どんな攻撃でも中断される |

**呪い**は敵があなたにかけるもの、**エンチャント**はあなた自身や味方がかけるものです。それぞれ専用の種類のスキルで除去されます。一部のエンチャントは**維持**されます。自分で終わらせるまで続き、続く間はエナジーのピップを1つ消費します。終わらせるには、そのアイコンをダブルクリックします。

いくつかのスキルは、エンチャントがかかっている間は効果がなくなり、エンチャントがなくなると再び効果を発揮します。「次のN回の攻撃」の間続くスキルは、すべての攻撃を数えます。そのため、外れても防がれても、当たったときと同じように1回分を消費します。

## 防御力とダメージ

WarriorとParagonは最も多くの防具を身に着け、Ranger、Assassin、Dervishはそれより少なく、術者は最も少なく身に着けます。防御力は、武器、元素、混沌、闇のダメージを小さくします。神聖、影、種類なしのダメージ、ヘルスの減少、生命力の吸収は防御力を無視します。クリティカルになるのは武器による攻撃だけです。一部のエンチャントは、それを受けた者をクリティカルヒットに対して無敵にします。

## 死亡、蘇生、モラル

ほとんどのモードでは、死んだ者は、味方がResurrection Signet（誰でも持てます）のようなスキルで**蘇生**させるまで倒れたままです。死者がウェーブごとに、あるいは自然に戻ってくるモードもあります。[モード](modes.md)を参照してください。

死ぬたびに**モラル**が15%下がり、最低-60%になります。それに伴い、最大ヘルスと最大エナジーも減ります。チームが敵を1人倒すごとに2%ずつ取り戻し、0まで回復します。ギルドバトルでは、旗台を確保するとそれを超えて、最大+10%まで上がります。
